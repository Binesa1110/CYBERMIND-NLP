What CYBERMIND does

Four analysis layers, one clear verdict

NLP Analysis

Tokenisation, stop-word removal, stemming, lemmatisation, part-of-speech tagging, and named-entity recognition with NLTK.

Machine Learning

A TF-IDF and logistic-regression classifier predicts benign, phishing, scam, or social-engineering intent with probabilities.

Keyword Detection

Security indicators such as urgency, credential requests, financial lures, threats, and social-engineering language.

URL Analysis

Extracts links and checks for missing HTTPS, IP-address hosts, excessive subdomains, long URLs, and suspicious terms.

Pipeline

How the analysis works

This describes the actual implementation in this project, not a generic marketing pipeline.

  1. 1

    Message submitted

    The browser sends the text to POST /analyze. The backend validates it and enforces a maximum length.

  2. 2

    Text preprocessing

    NLTK tokenises the text, removes URLs and stop words, then produces stemmed and lemmatised tokens, POS tags, and named entities.

  3. 3

    Keyword and indicator analysis

    TF-IDF extracts important terms. Rule-based patterns detect urgency, credential requests, financial lures, threats, scams, and social-engineering language.

  4. 4

    Machine-learning classification

    The trained model — TF-IDF features plus logistic regression — returns a predicted class and a probability for each class.

  5. 5

    URL analysis

    When links are present, heuristics check the scheme, hostname, length, subdomain count, and suspicious terms. No external reputation service is called.

  6. 6

    Threat assessment

    The decision engine combines heuristic evidence, ML confidence, URL indicators, and security indicators into a final threat, a 0–100 risk score, and a risk level.

Implemented vs. not implemented

Implemented in this project

  • NLTK preprocessing and sentiment (VADER)
  • TF-IDF keyword extraction and security indicators
  • Local trained ML classifier
  • URL heuristic inspection
  • Heuristic + ML decision fusion

Not implemented

  • External threat-intelligence or reputation feeds
  • Domain age, WHOIS, or certificate checks
  • Attachment, file, or malware scanning
  • Browser-extension or real-time inbox monitoring
  • Deep-learning or large-language-model analysis

About

About CyberMind NLP

Project objective

CyberMind NLP is an educational cybersecurity text-analysis project. It helps users examine suspicious messages by combining classical NLP, transparent heuristic rules, URL inspection, and a locally trained machine-learning model.

It is designed to explain why a message looks risky by showing the signals that contributed to the assessment.

Technologies used

  • Backend Python, FastAPI, Uvicorn
  • NLP NLTK, scikit-learn TF-IDF
  • ML Logistic Regression (scikit-learn)
  • Model file joblib
  • Frontend HTML5, CSS3, vanilla JavaScript
  • Storage Browser localStorage

NLP & machine learning overview

Text is normalised and tokenised, then converted into TF-IDF n-gram features. The classifier estimates probabilities for four classes: benign, phishing, scam, and social engineering.

Heuristic rules and URL indicators provide independent evidence. The decision engine blends these signals; the result is a transparent assessment, not a guarantee.

Cybersecurity threat detection

Social-engineering messages often combine urgency, authority, fear, and a request to click, pay, or disclose credentials. CyberMind looks for those patterns and highlights them, so you can verify the sender through an independent, official channel.

No accuracy percentage, certification, or external dataset is claimed here. Performance depends on the bundled training data and the message being analysed.
